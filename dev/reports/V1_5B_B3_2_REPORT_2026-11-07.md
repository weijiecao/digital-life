# V1.5-B B3.2 工程报告：约束归属耐用性

- 报告编号：DL-V1.5-B-REP-005
- 日期：2026-11-07
- 对应计划：B3 约束归属的耐用性补强
- 状态：**完成；仍不接入生产**

## 1. 新增保护

| 保护 | 行为 |
|---|---|
| 多个 `SAME_EVENT` | 同一 query 同时标多个事件为 SAME 时，全部 `CONFLICT`，不 attach |
| 重启幂等 | 关闭/重开 V1.5 后，同一 source 再次 resolve 只记 `ALREADY_ATTACHED` |
| cannot-link 持久化 | 关闭/重开后仍阻止冲突归属 |
| 追加决策 | `event_link_proposal` / `event_link_decision` 保留历史 |

## 2. 测试

| 测试 | 断言 |
|---|---|
| `test_resolver_rejects_multiple_same_proposals` | 2 个 SAME → 2 个 CONFLICT，0 evidence |
| `test_resolver_attachment_survives_reopen` | 重开后事件归属仍在；重复 resolve 幂等 |
| 既有 cannot-link 测试 | 冲突时 0 attach |
| 既有 RELATED 测试 | 不 attach |

## 3. 结果

| 项 | 结果 |
|---|---|
| 全量 | **381/381 通过** |
| V1.5 单测 | **18/18 通过** |
| B3.1 回放 | 54/80 正确，0 错误 |
| B2 三次重复 | precision 1.0；recall 0.6375–0.675 |

## 4. 边界

- 仍未做 batch=8/20/40 的 Resolver 端到端；
- 未做真实语料；
- 未做进程 kill 后的事务恢复；
- 未做删除后 cannot-link/证据重建；
- 合成数据，不能当发布验收。

## 5. 结论

B3 的安全边界现在更完整：

```text
多 SAME 歧义 → CONFLICT
cannot-link → 拒绝
重启 → 幂等
```

但覆盖率受 B2 recall 限制，仍约 65%。下一步 B4 必须用真实语料，不再用合成集调参。
