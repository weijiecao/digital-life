## 2. 实现

新增：

| 文件/表 | 内容 |
|---|---|
| `v1_5_consolidator/resolver.py` | `ConstrainedResolver` |
| `event_link_proposal` | 模型关系提议、标签、理由、模型版本 |
| `event_link_decision` | ATTACHED / ALREADY_ATTACHED / CANNOT_LINK / RELATED_ONLY / DEFERRED / CONFLICT |
| `event_cannot_link` | 事件级不可合并约束，规范化 `(event_a, event_b)` |

决策规则：

```text
SAME_EVENT
  → 检查 source 已属事件与 target 是否存在 cannot-link
  → 有冲突：CONFLICT，不 attach
  → 无冲突：ATTACHED 或 ALREADY_ATTACHED

DIFFERENT_EVENT
  → 对 source 已属事件与 target 建 cannot-link
  → 不 attach

RELATED_CONTEXT
  → RELATED_ONLY，不 attach

UNCERTAIN / 非法
  → DEFERRED，不 attach
```

关键安全点：

- **不做 Union-Find 传递合并**；
- cannot-link 优先于 SAME_EVENT；
- 所有归属是追加式 decision，可审计/撤销；
- 不写 V1 `events`，不创建正式事件。
