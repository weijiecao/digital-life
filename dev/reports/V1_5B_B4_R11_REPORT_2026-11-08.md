# V1.5-B B4-R11 叙事隔离探测报告

- 报告编号：DL-V1.5-B-REP-010
- 日期：2026-11-08
- 数据：Synthetic B4 v1（real_chat_records=0）
- 状态：**完成一个 50 对叙事探测；不是完整 R11 验收**

## 1. 方法

从 B4 fixture 中选出一侧事件类型为 `narrative`、另一侧为非 `narrative` 的 pair：

- 每条 query 只给一个候选事件；
- 使用当前 `RelationJudge`；
- 统计是否把叙事消息判成 `SAME_EVENT`（潜在误归因）。

## 2. 结果

| 指标 | 值 |
|---|---:|
| 探测 pair | 50 |
| `DIFFERENT_EVENT` | 50 |
| `SAME_EVENT` | **0** |
| 其他标签 | 0 |
| 叙事误归因 | **0 / 50** |

## 3. 判读

在这个合成探测中，叙事消息没有被判成与非叙事事件同一事件。  
这说明当前 prompt 在**明确叙事事件类型 vs 普通事件**的隔离上有基本保护。

但不能据此说 R11 通过：

- 样本是合成的；
- 只覆盖“叙事事件 vs 非叙事事件”，没有覆盖：
  - 第一人称虚构；
  - 朋友转述；
  - 叙事嵌套；
  - “刚才那段是编的”纠错反转；
- 只给一个候选，不是完整候选集；
- 0/50 不等于真实错误率为 0；
- 没有评估 `narrative` 事件内部的归属质量。

## 4. 测试

| 项 | 结果 |
|---|---|
| 全量 | **411/411 通过** |
| V1.5 单测 | **18/18** |
| B4 fixture | **3/3** |
| B4 reliability | **11/11** |
| R11 探测 | 50 对，0 SAME |

## 5. 结论

**R11 目前是“部分探测通过”，不是完整验收。**  
下一步需要专门的叙事夹具，覆盖第一人称虚构、转述、嵌套和纠错反转，并与用户亲历事件分开评估。
