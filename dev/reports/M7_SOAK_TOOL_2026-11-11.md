# M7 Shadow Soak 采样工具

- 日期：2026-11-11
- 状态：**可执行 72h 采样器；尚未运行 72h**
- 位置：`dev/host_shadow/soak.py`

## 1. 用法

```powershell
$env:ASTRBOT_ROOT='...\instance'
python dev/host_shadow/soak.py --interval 300 --hours 72 `
  --out dev/reports/shadow_soak.jsonl
```

`--once` 只采样一次。

## 2. 当前采样

{"db_exists": true, "log_exists": true, "events": 32,

## 3. 指标

- events / sources / scopes；
- valid evidence；
- observation 行数；
- log 字节数；
- DB/log 是否存在；
- SQLite 错误。

## 4. 边界

- 采样器不是消息生成器；
- 没有 72h 运行；
- 没有告警；
- 没有自动回退；
- 不是 R1 验收。
