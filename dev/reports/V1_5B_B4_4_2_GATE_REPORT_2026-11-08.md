## 1. 实现

新增 `v1_5_consolidator/evidence_gate.py`：

- 默认关闭；
- 不读 V1、不调用模型、不写事件；
- 只接收来源文本、候选锚点、关系提议；
- 输出 `ALLOW / ABSTAIN / REJECT` + reason codes。

规则：

| 规则 | 结果 |
|---|---|
| 没有 SAME proposal | ABSTAIN |
| 多个 SAME 目标 | ABSTAIN |
| 弱指代且无词面锚点 | ABSTAIN |
| 无词面锚点 | ABSTAIN |
| 候选缺失 | REJECT |
| 明确日期冲突 | REJECT |
| 有词面锚点且无冲突 | ALLOW |

新增 6 项单测。

## 3.1 固定 trace 的配对 Gate 效果

使用 T1 后的单次 R12 trace（不重新调用模型），对同一批 227 个 SAME proposal 做确定性 Gate：

| 结果 | 数量 |
|---|---:|
| Gate ALLOW + 目标正确 | 201 |
| Gate ABSTAIN + 目标正确 | 16 |
| Gate REJECT + 目标正确 | 10 |
| Gate 拦截 + 目标错误 | **0** |

结论：

- 在这条 trace 里，Gate 没有任何错误目标可拦；
- 它拦掉了 26 个**正确** SAME；
- `multiple_same_targets` 与 `explicit_date_conflict` 发生了假阳性；
- 因此当前 Gate 规则**只有召回损失，没有安全收益**；
- 必须保持默认关闭，不能作为“减少歧义”的已证明方案。

**注意：** 这是单条 trace 的配对结果，仍不是多种子/多模型分布；但比未配对开关对照更强。

## 3. 判读

- Gate 消除了 12 个 FP，但代价是 25 个 TP 丢失，F1 从 0.905 降到 0.886；
- Gate 没有减少 20 个 ambiguous 强制归属；
- 当前规则更像“降召回换零误合并”，不是解决歧义根因；
- **这不是配对实验**：Gate 开关各自重新调用模型，差异包含模型 run-to-run 波动，不能把全部差异归因于 Gate；
- 因此 **默认关闭，不进入生产**。

## 4. 结论

EvidenceGate 需要先在**固定 B2 预测**上做配对回放，才能判断净收益。  
当前证据不足以启用。
