- 报告编号：DL-V1.5-B-REP-012
- 日期：2026-11-08
- 数据：Synthetic B4 v1（real_chat_records=0）
- 状态：**默认关闭的实验 Gate；未证明净收益**

## 1. 实现

新增 `v1_5_consolidator/evidence_gate.py`：

- 默认关闭；
- 不读 V1、不调用模型、不写事件；
- 只接收来源文本、候选锚点、关系提议；
- 输出 `ALLOW / ABSTAIN / REJECT` + reason codes。

规则：

| 规则 | 结果 |
|---|---|
| 没有 SAME proposal | ABSTAIN |
| 多个 SAME 目标 | ABSTAIN |
| 弱指代且无词面锚点 | ABSTAIN |
| 无词面锚点 | ABSTAIN |
| 候选缺失 | REJECT |
| 明确日期冲突 | REJECT |
| 有词面锚点且无冲突 | ALLOW |

新增 6 项单测。

## 2. 探索结果（非配对实验）

| 指标 | Gate 关闭 | Gate 开启 |
|---|---:|---:|
| Pairwise precision | 0.97136 | **1.00000** |
| Pairwise recall | 0.84792 | 0.79583 |
| Pairwise F1 | **0.90545** | 0.88631 |
| TP / FP / FN | 407 / **12** / 73 | 382 / **0** / 98 |
| False merge | 0.268% | **0%** |
| Coverage | 1.000 | 1.000 |
| ambiguous 强制归属 | 20 | **20** |
| Gate allow/abstain/reject | — | 201 / 100 / 10 |

## 3. 判读

- Gate 消除了 12 个 FP，但代价是 25 个 TP 丢失，F1 从 0.905 降到 0.886；
- Gate 没有减少 20 个 ambiguous 强制归属；
- 当前规则更像“降召回换零误合并”，不是解决歧义根因；
- **这不是配对实验**：Gate 开关各自重新调用模型，差异包含模型 run-to-run 波动，不能把全部差异归因于 Gate；
- 因此 **默认关闭，不进入生产**。

## 4. 结论

EvidenceGate 需要先在**固定 B2 预测**上做配对回放，才能判断净收益。  
当前证据不足以启用。
