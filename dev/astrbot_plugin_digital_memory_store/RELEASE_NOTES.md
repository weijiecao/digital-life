# 发布说明 v1.0.7

**只改 README，不动代码**：把“支持什么、不支持什么”写在最显眼的位置。

## 改了什么

- 顶部加徽章：release 版本、许可证、AstrBot 4.29.3、Python 3.12；
- 加兼容性块：**AstrBot 4.29.3 实测通过；4.x 其他版本未验证**，并指向
  [`docs/QUICKSTART.md`](docs/QUICKSTART.md) 的 4 个检查点，让用户先自测再依赖；
- 安装文档里的 zip 文件名同步到 1.0.7。

## 为什么单独发一版

徽章和“已验证版本”都是给用户的承诺。之前只在 `INSTALL.md` 的前置表格里写了一行“4.29.3 实测，
其他 4.x 未验证”，容易被跳过；放到 README 顶部 + 加粗兼容性说明，减少“装到 4.30 上报错”的来回。

## 装法（同 v1.0.5 起）

```powershell
# 解压后进入插件目录
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
# 全自动
.\install.ps1 -AstrBotRoot "C:\AstrBot" -QQ 123456 -WithDeps -WithModel
```

装完按 [docs/QUICKSTART.md](docs/QUICKSTART.md) 的 4 个检查点确认：加载 / 命令 / 采集 / 注入。

## 已知限制

- 只支持私聊纯文本；群聊/图片/语音/多设备不支持。
- 语义阈值基于自造语料，真实分布下可能下降。
- 指代追问默认接不住；开启候选筛选器会外发原话。
- 纠错是“新旧并列 + 未确认”，不是自动改事实。
