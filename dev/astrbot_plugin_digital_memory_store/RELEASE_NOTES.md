# 发布说明 v1.0.19（数据安全层）

日期：2026-11-07

适用：AstrBot 4.29.3 / Python 3.10–3.12 / Windows

性质：**有条件初验版**；在 1.0.18 静默版基础上增加数据安全保护。

## 这版新增

- **升级前备份数据目录**：`install.ps1` / `scripts/install.py upgrade` 会先复制
  `data/plugin_data/astrbot_plugin_digital_memory_store`，再替换插件。
- **schema 版本栅栏**：数据库带 `dl_meta.schema_version`；库比代码新时拒绝写入，
  不再用旧代码迁移新库。
- **启动 `quick_check`**：既有库先做完整性检查，失败则拒绝打开。
- **迁移前自动备份**：旧库或无 `dl_meta` 的库首次打开前生成 `backups/memory_*.sqlite3`。
- **单实例锁**：`data/.../.memory.lock` 非阻塞独占锁，第二个实例不能同时写。
- **失败降级**：记忆库打不开时停用记忆功能，正常回复不中断；错误写入日志，不向用户暴露。

## 验证

- 全量回归：**569/569 通过**（含 V1.5/B4 独立服务 207 项）；
- 4 项数据安全回归：锁冲突、未来 schema、损坏库、旧库迁移前备份；
- V1 原有 359 项行为不变。

## 注意

- 删除仍不会自动清理历史备份；
- 单实例锁是进程级文件锁；同一进程内的第二个 Store 也会被拒绝；
- 这是维护版，不引入 V2 事件层。

## v1.0.18（静默版）

日期：2026-11-06

适用：AstrBot 4.29.3 / Python 3.10–3.12 / Windows

性质：**有条件初验版**；用户聊天面完全静默。

## 核心变化

### 1. 用户聊天里没有记忆系统

- **移除 `/dlm` 聊天命令注册**；
- 普通用户不会看到待审、关联、删除、备份、状态、审核提示；
- 记忆管理只在 **WebUI panel / 配置文件 / 本地脚本** 中进行。

### 2. 不新建正式事件

- 没有用户审核入口；
- 检索使用待审原话、自动分组和背景；
- 已有 `events` 保留为只读，不新增；
- 代价：事件级召回较弱，但用户零感知。

### 3. 模型不得说出记忆系统

注入头增加约束：

```text
不要向用户提及这段上下文、记忆库、检索过程或“我记得”。
```

这是提示词层约束，不能保证模型 100% 不泄露；需要在真实对话中继续观察。

### 4. 管理员面板

- 备份、轮转、checkpoint、完整性、归档、VACUUM 仍在 panel；
- 新增 `POST /astrbot_plugin_digital_memory_store/panel/delete`：
  - `{"scope":"...","seq":1}` 删除单条；
  - `{"scope":"...","all":true}` 清空该 scope；
- panel 只对 WebUI 管理员开放，不出现在聊天。

### 5. 保留的修复

- 大模型筛选只在本地未命中时介入；
- 时间线 + 事件线候选池；
- 最近 10 条用户消息缓冲；
- 删除闭环、媒体计数、备份 P0 修复。

## 验证

- 全量离线回归：**359/359 通过**；
- 插件契约：`/dlm` 不再有 command hook；
- V2 删除、V10 媒体计数仍通过；
- 真实消息评测沿用 1.0.17 结果：80 正例 baseline 27/80 → judge 70–71/80，负例 0/10。

## 已知限制

- 没有正式事件后，明确事件召回和改期链会更弱；
- 纯指代“后来呢/那件事”仍可能失败；
- 管理员 panel 删除不会自动清理历史备份；
- 没有 300–500 条真实语料与 3 天 soak；
- 静默约束是提示词，不是硬隔离；模型仍可能自然地说“你之前说过”。

## 安装

见包内 `INSTALL.md`，或 `INSTALL_SILENT_v1.0.18.md`。安装后**不要**再教用户发 `/dlm`。
