## 为什么是“检查点”而不是“装完即可”

这个插件默认停用，而且语义召回依赖本机模型——所以“装上”不等于“能用”。四个检查点分别验证：

1. 插件被 AstrBot 加载（目录名、日志）；
2. 命令通道通（`enabled`、私聊、白名单）；
3. 采集落库（`/dlm 记忆状态` 计数增长）；
4. 注入生效（回复或日志里出现 `[DL_MEMORY …] 未确认` 片段）。

第 4 条不通过的常见原因是没模型：此时记录/查看/备份仍然正常，只是注入退化为字面/背景路径。

## 安装（同 v1.0.5）

```powershell
# 解压后进入插件目录
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
# 全自动
.\install.ps1 -AstrBotRoot "C:\AstrBot" -QQ 123456 -WithDeps -WithModel
```

## 已知限制

- 只支持私聊纯文本；群聊/图片/语音/多设备不支持。
- 语义阈值基于自造语料，真实分布下可能下降。
- 指代追问默认接不住；开启候选筛选器会外发原话。
- 纠错是“新旧并列 + 未确认”，不是自动改事实。
