## 这个插件是什么

AstrBot 私聊纯文本记忆：原话存本机 SQLite，每轮给模型一段**有界上下文**（默认 450 字，上限 600），
一律标注“未确认”，不自动确认事实；默认关闭，除显式开启的候选筛选器外不联网。

## 安装

见 `INSTALL.md`。最短路径：解压到 `<AstrBot根>/data/plugins/` → 重启 → WebUI 插件配置里打开
`enabled`、`automatic_memory_enabled`，填 `allowed_sender_ids`。

需要语义召回再装 `requirements.txt` 里的依赖并把 `model_dir` 指向本机 BGE 目录；没有模型也能记录与查看。

## 已知限制

- 只支持私聊纯文本；群聊/图片/语音/多设备不支持。
- 语义阈值与窄路参数基于自造语料，真实分布下可能明显下降。
- 指代追问默认接不住；开启候选筛选器会外发原话。
- 纠错是“新旧并列 + 未确认”，不是自动改事实。
