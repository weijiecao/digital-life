# 发布说明 v1.0.3

## 这是什么

数字生命独立记忆库（自用版）：AstrBot 私聊纯文本记忆插件。本地存储与本地语义召回，
**默认每轮都给模型一段有界上下文**（相关证据优先；无匹配时给较早原话作背景），
一律标注“未确认”，不自动确认事实；默认关闭，除显式开启的候选筛选器外不联网。

## 交付内容

- 插件本体（本目录）
- `INSTALL.md`：安装、升级、回退、隐私、常见问题
- `CHANGELOG.md`：版本变更
- `presets/`：off / self / debug 三档配置
- 仓库内 `dist/`：zip + SHA256（用于分发）

## 已知限制

- 只支持私聊纯文本；群聊/图片/语音/多设备不支持。
- 语义阈值与窄路参数基于自造语料，真实分布下可能明显下降。
- 指代追问默认接不住；开启候选筛选器会外发原话。
- 纠错是“新旧并列 + 未确认”，不是自动改事实。

## 安装

见 `INSTALL.md`。升级前请用 `upgrade.py` 自动备份；回退用 `rollback.py`。
