# 插件测试前功能清单（E5.0-F，v0.15.116）

## 验收目标

正常聊天时自动采集、组织、检索与更新记忆，不要求用户处理审核；保留原话与不确定性。所有离线测试通过不能代替真实模型和平台测试。

## 当前已具备的离线流程

- 授权私聊纯文本采集、独立库、时间信息、候选整理与持久化任务。
- 本地增量向量索引、未归组原话和自动推测事件的受限检索。
- 相邻固定短句可能更新、可选模型关系线索、完整原话与不确定性标记。
- 有限短追问、提取式上下文压缩、近期与重复自述的弱排序信号。
- 已检测的采集缺口保护、后台失败重试、备份与隔离恢复雏形。

## 插件测试前仍需完成的主要工作

1. **自动事件重定位**：已支持单条归并、来源变化重整、双记录拆分、两个多成员事件的可撤销合并；有效反向线索可触发事件整体重建，跨时间反向线索在重建后继续绑定来源。后台持久游标轮询旧线索；重建、单条归并和两个多成员事件合并取消 100 条硬限制，但不保证任意规模的响应时间，也不保证所有来源重新归组成功；无明确反向线索时的误归类及复杂跨事件纠错未解决。
2. **事实变化闭环**：默认关闭的模型关系线索支持同事件及跨事件的受限语义比较、失效重试与短追问；共享来源的模型变化线索可以成链供给；归组完成可重新排队曾提前跳过的变化任务。不同表达、复杂指代、多条跨事件更正或取消仍不可靠，无法保证旧事实不会被错误理解为现状。
3. **长事件和上下文质量**：变化原话及来源绑定的模型关系可纳入有限摘取；跨事件变化检查具备持久化游标和增量变更队列，原话向量支持批量编码；语义召回减少候选内存占用。回填期及其他检索的完整扫描、单个大事件内存、比较次数、其他功能上限及超时仍是制约；需继续优化和真实性能验收。复杂多事件与多轮指代仍未完成。
4. **离线端到端验收**：需要覆盖连续会话、跨日补充、纠错、相似事件、故障重启、长历史与缺口恢复，报告误召回、漏召回及处理成本；当前固定场景和模拟编码器不代表真实效果。
5. **安装与兼容性准备**：整理配置、依赖、升级与回退路径；真实 Windows、AstrBot、NapCat 和 BGE 的测试仍是下一大节点，不应宣称已完成。

## 当前限制

默认自动模式须显式启用并配置授权私聊白名单。本地编码器目录需要配置；后台模型辅助默认关闭，若启用远程服务会发送相关原话并可能计费。现阶段仍是测试前开发版本，不建议作为生产记忆或完整聊天备份。
